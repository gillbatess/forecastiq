# Model artifacts

Generated by `python scripts/train_model.py`. Everything the deployed app needs is in here.

    holdout/      models fitted on data before 2012-01-01 (used to score 2012 weeks out-of-sample)
    production/   models fitted on all data (used for future weeks)
      point.ubj.gz      XGBoost point forecast (gzip-compressed UBJSON)
      quantile.ubj.gz   XGBoost 10%/90% quantile model (prediction interval)
      aggregates.json   store/department averages fitted on that phase's training window
    reference/    compact copy of the sales history, indicator table and store list
    model_metadata.json   model card: parameters, metrics, baselines, calibration
